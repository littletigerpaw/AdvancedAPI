# Submission Checklist

## Before recording
- [ ] Make sure the Flask app is running
- [ ] Test the API in Postman or with curl
- [ ] Confirm the token login flow works
- [ ] Confirm service tickets and inventory routes work
- [ ] Confirm the app passes pytest

## During the video
- [ ] Show your face on camera
- [ ] Explain what the project does
- [ ] Explain how it works at a high level
- [ ] Show the project running
- [ ] Keep the video under 5 minutes

## After recording
- [ ] Upload the video directly to Disco
- [ ] Copy your GitHub repository URL
- [ ] Submit the GitHub link in the assignment field
- [ ] Make sure the video is attached directly, not via Google Drive
